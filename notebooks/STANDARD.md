# Shared example standard

These examples follow the [v0.3.32 shared standard](https://github.com/Query-farm/vgi-example-notebooks/blob/v0.3.32/docs/standard.md) and [coverage evidence format](https://github.com/Query-farm/vgi-example-notebooks/blob/v0.3.32/docs/coverage.md).

SVG is the default figure format. Notebook setup pins the shared base package, local execution uses its locked runner extra, and immutable companions are hash-verified. Worker source and root dependency locks are unchanged; existing green source CI is reused.
